# How to Start Market Lens

## Always use this method:
Double-click `start_marketlens.bat` on the desktop.

## Or manually:
1. Open terminal
2. cd C:\Users\User\.cursor\worktrees\Market_Lens\avi
3. venv\Scripts\activate
4. streamlit run app.py
5. Open http://localhost:8501

## Never run from:
- C:\Users\User\Downloads\DuoWeave\Market Lens (this is for documents only)
- Any other path

## If localhost refuses connection:
The app is not running. Double-click start_marketlens.bat.

## Python/venv path:
C:\Users\User\.cursor\worktrees\Market_Lens\avi\venv\Scripts\python.exe

## Database:
PostgreSQL - market_lens - localhost:5432 - postgres/postgres
